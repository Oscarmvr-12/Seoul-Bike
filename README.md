# Seoul-Bike

CDS 303 (Scientific Data Mining) Final Project, Team 8: **Dae Yeong Mun** and **Oscar Molina Romualdo**.

An explainable cluster analysis of Seoul's public bike-share system (Ttareungi, 따릉이), using trip-level rental history for January–June 2026.

**Project website:** <https://oscarmvr-12.github.io/Seoul-Bike/>

## Repository layout

| Path | Contents |
|---|---|
| `docs/` | Written project sections, published with GitHub Pages |
| `notebooks/` | Supporting Jupyter notebooks |

## Data

Raw data files are **not** stored in this repository. The main trip file is about 3.1 GB, which exceeds GitHub's file-size limit. Download links for every dataset are on the [Supplementary Data page](https://github.com/Oscarmvr-12/Seoul-Bike/blob/main/docs/supplementary-data.md). To run the notebooks, place the downloaded CSV files in the same folder as the notebook.
